# rep-mind-map

> Одна команда — и архитектура JS/TS-проекта как на ладони: интерактивный граф до уровня функций и классов, локально и без настройки.

```bash
npx rep-mind-map ./src
```

> **Статус:** в разработке. Описание ниже — целевое поведение первой версии (MVP).

---

## Идея

Когда приходишь в чужой проект или возвращаешься к своему через несколько месяцев, нужно время, чтобы снова понять, как всё устроено: какие есть модули, кто кого вызывает, что сломается при изменении функции.

**rep-mind-map** показывает это визуально. Он анализирует локальный JS/TS-проект и строит интерактивный граф, где узлы — модули, классы и функции, а рёбра — импорты и вызовы между ними.

## Чем отличается от аналогов

Madge, dependency-cruiser и подобные инструменты показывают связи только между **файлами**. CodeSee показывает больше, но работает в облаке и требует регистрации.

rep-mind-map:

- **Видит функции и классы**, а не только файлы: всё, что имеет область видимости, становится узлом графа.
- **Показывает вызовы**, а не только импорты: видно, кто кого реально вызывает.
- **Работает локально**: код не покидает компьютер, никакой сети и регистрации.
- **Подсвечивает проблемы**: циклические зависимости и сломанные импорты видны сразу.

## Как работает

1. Вы запускаете `npx rep-mind-map <путь к папке проекта>`.
2. Инструмент находит файлы `.ts` / `.js`, разбирает их и выделяет модули, классы, функции и методы.
3. Определяет связи между ними — импорты и вызовы, отмечает сломанные связи и циклы.
4. Сохраняет один самодостаточный `index.html` и открывает его в браузере.
5. В браузере вы двигаете и приближаете граф, раскрываете узлы и смотрите связи любого элемента.

Если в каком-то файле синтаксическая ошибка, он пропускается, а анализ продолжается — в конце будет список неразобранных файлов.

## Архитектура

Синхронный конвейер из пяти модулей:

```
CLI → Parser → Graph Builder → HTML Generator → index.html (Renderer в браузере)
```

| Модуль | Что делает |
|---|---|
| CLI | Принимает путь, запускает анализ, показывает ход работы и итог, открывает браузер |
| Parser | Разбирает `.ts` / `.js` файлы (ts-morph) и извлекает модули, классы, функции, импорты и вызовы |
| Graph Builder | Строит граф `{ nodes, edges }`, определяет состояние связей, ищет циклы |
| HTML Generator | Упаковывает граф и код отрисовки в один `index.html` |
| Renderer | Рисует граф в браузере на D3.js: зум, перетаскивание, клик для деталей |

Модули связаны через контракт `{ nodes, edges }`, поэтому визуализацию можно заменить, не трогая разбор кода.

## Стек

Node.js ≥ 22 · TypeScript · ts-morph · D3.js · Vitest

## Границы

В первой версии:

- только JavaScript и TypeScript (ES2015+);
- только локальные проекты (путь к папке);
- запуск из командной строки, без установщика;
- без сервера и базы данных — каждый запуск независим.
